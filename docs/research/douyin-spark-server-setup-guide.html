选购 + 部署手册

2核2G 轻量服务器：买什么，以及怎么装

按你的实际情况定制：单抖音账号、10~50 个好友、国内云服务器、每月 20~40 元。本手册分两部分——先解决"买哪台、买哪个档、哪些选项别勾"，再给一份可以照着敲的部署流程，每一步都写明作用、注意事项和验证方法。

01先定配置：为什么是 2核2G / 3M

这个项目的资源画像很特殊——它几乎不吃 CPU、不吃带宽，但吃内存，因为要在服务器上跑一个真实的 Chromium。

资源实际消耗结论
内存 Playwright 驱动的无头 Chromium 单实例 400~700MB；Python 服务 + APScheduler 约 150~250MB。合计 0.6~0.95GB 2G 是底线 1G 会 OOM，必须靠 swap 硬撑，发送中途被杀会导致"发了半条"
CPU 每天只跑一次、每次几十分钟，其余 23 小时空闲；单核足够 2 核是送分题 主要是给 Chromium 多进程留余量，1 核也能跑
带宽 只用于浏览器加载抖音聊天页，不对外提供服务；单页浏览峰值约 1~2Mbps 3M 够用 别为带宽加钱，也别买 200M 锐驰型
流量 每天几十 MB（头像、少量图片），月合计 2~5GB 200GB 套餐绰绰有余 前提是别在服务器上开浏览器刷视频
系统盘 系统约 3G + Chromium 约 150MB + 依赖约 500MB + 日志 40G 够 50G 更宽松，差几块钱可以要

一个必须纠正的常见误解：备案

很多人以为"国内服务器必须备案才能用"。备案是针对域名的——只有你把域名解析到内地服务器、并通过 80/443 端口对外提供网站时才需要 ICP 备案。

你这个场景是 http://服务器IP:8000 直接访问管理面板，不涉及域名、不需要备案，买完实名认证完成就能用。

给你的结论

腾讯云轻量应用服务器，内地地域，2核2G / 40G SSD / 3M / 200GB，Ubuntu 24.04 LTS。

先买月付 ¥40 跑一个月，确认整条链路（扫码、定位好友、真发出去）能通，再转年付 ¥408（合 ¥34/月）。多花这 ¥28 是买保险——万一这套东西在你的账号上跑不通，月付止损比年付退款省事得多。

下单时必须做的四个选择

  1. 地域选你所在城市或最近的节点。这是最重要的一项。抖音对"异地登录"敏感，服务器 IP 与手机常用地越接近，触发短信/刷脸验证的概率越低。别选香港或海外（你的选择是对的）。
  2. 镜像选 Ubuntu 24.04 LTS（纯净系统），不要选 Windows、不要选宝塔/WordPress 应用镜像。Windows 镜像要额外收费且 2G 内存跑不动；宝塔面板会白占内存和端口，你根本用不上。
  3. 系统盘 40G 起步。低于 40G 装完 Chromium 和依赖后余量紧张，日志一多就满。
  4. 先月付，别一上来买三年。轻量套餐续费按原价，新用户首单 1.4 折这类优惠只有一次，先跑通再锁长期。

这几样别买（销售页会顺手推荐）

  • 数据盘——40G 系统盘够，挂载数据盘只会让你多一步 fdisk 的麻烦。
  • 快照/备份套餐——第一周不需要，等跑稳了再说，数据你自己 scp 拉回本地更实在。
  • DDoS 高防、CDN、SSL 证书——你连域名都没有，全部无关。
  • "代部署/代挂机"服务——等于把账号 Cookie 交给陌生人，这是本次调研里风险最高的一件事。

03为什么这次不装 S 级那个项目

上一轮我把 halfwaystudent/douyin-sparkflow 评为 S 级，那是按"功能完整度 + 活跃度"排的。放到你这台 2核2G 上，结论要改。

项目部署形态2核2G 上能不能跑结论
halfwaystudent/douyin-sparkflow Docker Compose 五个容器：web + scheduler + login-desktop(内含 Chromium + noVNC) + mihomo 代理 + task 勉强 光登录桌面容器就是 500~700MB，再叠加 web 与代理，2G 会持续 swap 抖动，README 自己写的要求是 2 核 2G "或以上"、10G 存储 留到你升级 2核4G 再上
Xiaowu-0916/douyin-spark FastAPI + Playwright + APScheduler，单进程单服务，自带 deploy/deploy.sh 一键部署 + systemd 充裕 作者标注 1 核 1G 可跑（需 swap），2核2G 属于舒服档 本次部署主线
2061360308/DouYinSparkFlow 图形客户端为主 + Docker 镜像 Docker 单容器可跑，但图形界面在无头服务器上没意义 备选：适合你本地 Windows 上用

选它的三个实质理由（不只是"轻"）

1. 防发错人做得最细：点击联系人后会校验右侧会话标题是否为目标好友才继续发送，从机制上杜绝"发给上一个人"。这是这类工具最常见的翻车方式。

2. 失败有兜底：文字离开输入框才算发送成功；本轮失败的好友 45 分钟后自动补发一次，每天最多一次。

3. 有熔断：页面出现"操作频繁 / 安全验证"立即停掉本轮，不会继续硬发把风控等级越抬越高。

代价：只支持纯文本（你的需求够用），最后提交 2026-08-20，比 S 级两位安静。

04部署流程（照着敲）

共 9 步。带 本机 标记的在你的 Windows 上做，带 服务器 的在云服务器上做。每步都给了验证方式——没验证通过就不要进入下一步，这类部署 90% 的坑都是"跳过验证硬往下走"造成的。

00准备：买机器 + 放行端口控制台
做什么
按第 2 节下单。买完后进控制台 →「防火墙 / 安全组」，放行 22（SSH） 和 8000（面板）。
作用
轻量服务器默认只放行 22/80/443，不放行 8000 你永远打不开面板，而且报错是"连接超时"，很容易误判成服务没起来。
注意
来源 IP 一定要填你自己的公网 IP，不要图省事填 0.0.0.0/0。这个面板里有你账号的登录态，暴露在公网等于把抖音账号挂在网上。查自己 IP：浏览器搜"我的IP"。
验证
控制台显示两条规则，来源列是你的 IP（形如 1.2.3.4/32）。
01登录服务器并做基础加固服务器
做什么
Windows 自带 OpenSSH，直接在 PowerShell 里连（把 IP 换成你的）：
ssh root@你的服务器IP
作用
首次登录会提示 yes/no 确认指纹，输 yes 再输密码（腾讯云轻量默认给 root 密码，在控制台可以重置）。
接着做
更新系统、设时区、装 git —— 三件事一起做：
apt update && apt upgrade -y
timedatectl set-timezone Asia/Shanghai
apt install -y git curl
date
作用
时区必须设成上海。默认是 UTC，你设"21:00 发送"实际会在北京时间凌晨 5 点发出去。`date` 用于确认。
验证
date 输出里带 CST 且时间与北京时间一致，例如 Thu Oct 22 17:40:12 CST 2026。
02创建 swap（2G 内存的保险丝）服务器
做什么
项目自带的部署脚本会建，但建议你先手动建好，避免脚本中途失败留下半成品：
# 建 2G swap 文件
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# 验证
free -h
作用
Chromium 的内存峰值有波动。2G 物理内存 + 2G swap，意味着偶发峰值只会变慢而不会被 OOM Killer 杀掉。发送进行到一半进程被杀的后果是"消息发了一半/状态不明"，很麻烦。
注意
/etc/fstab 那一行是让它开机自动挂载，漏了这行重启后 swap 就没了。如果你的系统盘是 SSD 且剩余空间紧张，可把 2G 改成 1G。
验证
free -h 的 Swap 行显示总量 2.0Gi。
03拉取项目代码服务器
cd /opt
git clone https://github.com/Xiaowu-0916/douyin-spark.git
cd douyin-spark
ls
作用
放在 /opt 是 Linux 存放第三方应用的惯例目录，后续 systemd 服务的 WorkingDirectory 会指向这里。
注意
如果 git clone 卡住或报 TLS 错误，是服务器到 GitHub 的网络问题，先重试一次；仍不通就改用国内镜像或在你本机下载 zip 后用 scp 传上去。
验证
ls 能看到 app.py、extract_cookie.py、core/、static/、deploy/。
04在本机扫码，导出登录态本机 Windows
为什么不用服务器扫
这个项目的设计是登录态在本机扫码产生、服务器只复用。原因是抖音对"机房 IP 首次登录"很敏感，从你家宽带登录再拿凭证去服务器用，触发验证的概率更低。
做什么
在 Windows 上装 Python 3.11（安装时勾选 Add Python to PATH），然后把项目下载到本地，在项目目录里执行：
# 在项目目录打开 PowerShell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
python extract_cookie.py
作用
前四条是准备自动化环境（playwright install chromium 会下约 150MB 浏览器内核）。最后一条会弹出一个真实浏览器窗口，你用手机抖音扫码登录，脚本把登录态写进 data/state.json。
注意
扫码后不要立刻关窗口，等脚本提示导出完成。如果弹出短信/刷脸二次验证，就在手机上完成它——这一步绕不过去，也没有必要绕。
验证
本地出现 data\state.json，用记事本打开能看到 cookies 字段。这个文件等同账号密码，不要发到任何群里，也不要提交到 Git。
05把登录态传到服务器本机 Windows
# 在本地项目目录执行（scp 是 Windows 自带的）
scp data\state.json root@你的服务器IP:/opt/douyin-spark/data/
作用
服务器上的程序靠这个文件代表"你已登录"。
注意
如果 /opt/douyin-spark/data/ 不存在，先在服务器上 mkdir -p /opt/douyin-spark/data。传输走的是 SSH 加密通道，比网盘、微信传文件安全得多。
验证
在服务器上 ls -l /opt/douyin-spark/data/，能看到 state.json 且文件大小与本地一致。
06一键部署并启动服务服务器
cd /opt/douyin-spark
bash deploy/deploy.sh
作用
脚本会依次完成：装 Python 依赖 → 装 Chromium 系统库 → 生成随机访问令牌写入 .env → 注册 systemd 服务并启动。跑完会打印访问地址和令牌。
注意
令牌只打印这一次，立刻复制存好。如果漏了，用 cat /opt/douyin-spark/.env 找回。
验证
三连验证，全过才算起步成功：
systemctl status douyin-spark --no-pager   # 应为 active (running)
ss -tlnp | grep 8000                       # 应看到 0.0.0.0:8000 监听
curl -I http://127.0.0.1:8000              # 应返回 HTTP/1.1 200 或 401
若失败
先看日志再动手改：journalctl -u douyin-spark -n 80 --no-pager。常见原因是 Chromium 系统库缺失（playwright install-deps chromium 可补）。
07面板配置：勾好友、设时间浏览器
做什么
浏览器打开 http://你的服务器IP:8000，输入令牌。然后按顺序：
  1. 上传登录态：把第 05 步传上去的 state.json 在面板里上传/确认，顶部状态应变成"已登录"。
  2. 同步联系人：点「获取聊天列表」，等 10~30 秒。这一步会自动带出每个好友的火花天数。
  3. 勾选好友：按火花天数从高到低排好了，优先勾天数最多、最舍不得断的那几个。第一次只勾 1 个。
  4. 设时间：先设 21:00、随机浮动 ±30 分钟、好友间隔 6~12 分钟。改动实时生效。
注意
「获取聊天列表」只包含抖音网页当前已加载的会话，不是你完整的好友名单。找不到某个人，先在该账号的抖音网页里打开和他的会话，再回来重新读取。
验证
好友列表里有头像、有火花天数、勾选状态保存后刷新页面仍保留。
08干跑 → 真发 → 人工确认（关键一步）面板 + 手机
做什么
先点「干跑测试」（走完整流程但不真发），日志里应能看到"定位到好友 X / 校验通过 / 模拟发送"。确认无误后点「立即发送」。
为什么必做
干跑能验证"有没有定位到正确的人"，但验证不了"消息真的出去了"。只有你打开手机抖音、看到那条消息躺在对话框里，才算部署成功。这一步没做就等于没部署。
注意
如果日志里有"操作频繁/安全验证"，立刻停手，等几小时再说。继续重试只会把账号风控等级抬高。
验证
手机抖音 → 与该好友的聊天 → 看到你配置的那条文案，且时间对得上。
09收口：重启验证 + 安全收紧服务器 + 控制台
# 1. 验证开机自启（最重要的一个验证）
reboot
# 等待 40 秒后重新 ssh 进来
systemctl is-enabled douyin-spark
systemctl is-active douyin-spark
free -h
作用
is-enabled 返回 enabled 且 is-active 返回 active，说明云服务器被平台迁移/重启后能自己活过来——这是无人值守的前提。free -h 顺便确认 swap 还在。
接着做
回到控制台防火墙，把 8000 端口的来源 IP 收紧到你当前 IP（如果之前开得比较宽）；确认 22 端口也不是 0.0.0.0/0。
最后
在面板里把好友从 1 个扩到你真正要维护的数量（10~50 个），间隔保持 6~12 分钟不动。人数越多间隔要越大，50 个好友按 9 分钟均值算要跑 7 个多小时，跨到凌晨是正常的，不是卡住了。

05装完之后：日常运维清单

情况怎么判断怎么处理
登录态过期
最常见的"故障"，几天到几周一次		 面板顶部状态标红"登录态已过期"，或发送连续失败 回到第 04 步重跑 extract_cookie.py 扫码，再 scp 覆盖 data/state.json，面板重新上传即可。不需要重装、不需要重启服务
提示"操作频繁" 日志出现安全验证关键词，本轮被熔断 把好友间隔调到 15~20 分钟、单次人数减半，当天别重试。这是账号在被降权，加频率只会更糟
某个好友一直发不出去 日志显示"找不到会话/切换校验失败" 先在网页端手动打开和 TA 的会话，再重新"获取聊天列表"；确认用的是完整昵称/备注名
服务挂了 systemctl is-active 不是 active journalctl -u douyin-spark -n 100 --no-pager 看最后 100 行；多为内存不足或 Chromium 库缺失
抖音改版导致失效 大面积发送失败、页面元素定位不到 先去仓库看有没有 issue 和更新：cd /opt/douyin-spark && git pull && systemctl restart douyin-spark。data/ 是你的数据，pull 不会覆盖它
想备份 / 迁移 — 只需备份 /opt/douyin-spark/data/（含登录态、好友勾选、配置、日志）。scp -r root@IP:/opt/douyin-spark/data ./backup

三条不能碰的红线

1. 不要在服务器上开浏览器刷抖音。会白白吃掉流量包和内存，还会让这个 IP 的行为更像"机器"。

2. 不要把 8000 端口开放给 0.0.0.0/0。面板一旦被扫到，别人能直接看到你的好友列表和账号状态。

3. 不要用主号第一次试。先用小号跑通一轮（最好连续三天），确认不发错人、不漏发，再换主号。

价格以腾讯云官方定价文档（2026-09-24 更新）为准，阿里云部分为社区活动口径，实付价格请以下单页面为准，促销与库存会随时变化。部署步骤依据 Xiaowu-0916/douyin-spark 的 README（最后提交 2026-08-20）整理，若仓库后续改动导致脚本行为变化，以仓库最新 README 为准。本手册未在真实账号上完整执行过，执行中遇到与本手册不符之处，优先相信 journalctl 日志和仓库文档。
