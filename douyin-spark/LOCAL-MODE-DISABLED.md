## 为什么删了数据就"关不掉也发不出去"

即使误把 `app.py` 在本机启动，也不会发出任何消息，因为：

1. 没有 `state.json` → 执行时直接判定"尚未上传登录态"，本轮终止；
2. 没有 `config.json` → 好友名单为空，只会记一条"未配置任何好友，跳过发送"；
3. `.env` 已改为 `HOST=127.0.0.1` → 只能本机访问，局域网与公网都碰不到。

这是刻意设计的"物理卸载"：**不靠自觉，靠没有弹药。**

## 以后登录态过期了怎么办

在**本机**这个目录里执行（二选一）：

```powershell
# 方式一：双击运行
.\scan-only.ps1

# 方式二：手动
.\.venv\Scripts\python.exe .\extract_cookie.py
```

会弹出一个真实的 Chromium 窗口并打开抖音首页，用手机扫码登录，脚本检测到登录凭证后自动保存到 `data/state.json` 并关闭窗口（5 分钟不扫会自动超时退出）。

然后把生成的 `data/state.json` 上传到服务器面板：

```
http://你的服务器IP:8000  →  令牌登录  →  概览页「选择 state.json」→「上传登录态」
```

## 千万不要做的事

- ❌ 不要在本机执行 `python app.py` 或 `uvicorn`——本机没有数据，跑起来也没意义，只会占 8000 端口
- ❌ 不要为本机创建开机自启 / Windows 计划任务
- ❌ 不要把 `data/state.json` 发给任何人（它等于账号密码）
